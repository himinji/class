이제 여러분 차례. 스마트 응원봉을 직접 만들어 봅시다.

📋 응원봉 코드
⚠️ 구현할 때, 이 점을 주의해요
1

코드에 수정할 부분이 있어요

그대로 옮겨 적으면 응원봉에 불이 안 들어와요. 어딘가 한 곳, 고쳐야 할 부분이 있어요.

2

비교 연산에 주의!

receivedString은 문자열(글자)이에요. 비교할 때 문자열 비교 블록인지, 양쪽 글자가 정확히 같은지 잘 살펴봐요.

3

안 되는 기능이 하나 있을 거예요

코드 그대로 두면, 모드 중 하나가 제대로 작동하지 않아요. 어떤 모드인지, 왜 그런지 직접 디버깅해 봅시다.

전개 5 · 정답 공개 · Reveal

어디를 고쳤어야 했을까요?

정답 ①

핀 번호를 바꿔요

잘못된 코드 P0
→
올바른 코드 P1

LED 링은 실제로 P1 핀에 연결되어 있어요. NeoPixel 블록의 pin을 P0 → P1로 바꿔야 응원봉에 불이 들어와요.

💡 코드와 실제 회로의 핀 번호가 일치하는지 항상 확인하는 습관!

정답 ②

FLASH가 깜빡이지 않은 이유

strip clear 다음에 strip show가 빠져 있었어요.
clear는 메모리에서만 지우고, show를 호출해야 실제 LED에 반영돼요.
